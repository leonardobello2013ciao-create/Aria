# ARIA v3 — AI gratuita con Gemini

Questa versione è pensata per richiedere all'utente il minimo possibile.

## Primo avvio
1. Pubblica questa cartella su Netlify.
2. Apri ARIA.
3. Premi "Crea chiave gratuita".
4. Google AI Studio genera una Gemini API key.
5. Incolla la chiave in ARIA e premi "Attiva ARIA".

La chiave viene salvata in localStorage sul dispositivo e NON è inclusa nei file dell'app.

## Funzioni
- Chat con Gemini 3.7 Flash
- Personalità ARIA
- Memoria locale
- Regola: le informazioni non vengono salvate a lungo termine prima di 3 turni utente
- Progetti
- Reality Check intelligente
- Input vocale
- Sintesi vocale
- UI futuristica
- PWA installabile

## Limiti
- La ricerca web live non è ancora integrata nella versione gratuita.
- La generazione immagini Gemini via API non è inclusa nel free tier standard.
